# Сортируй, как сосед

Адаптивный одностраничный лендинг о сортировке отходов. HTML, CSS и JavaScript без зависимостей.

## Запуск

Откройте `index.html` в браузере. Для локального сервера выполните `python3 -m http.server 8000` и откройте http://localhost:8000.

## Файлы

- `index.html` — содержание и семантическая разметка.
- `style.css` — адаптивная вёрстка и анимации.
- `script.js` — выбор материалов, личный план и приглашение соседей.
- `courtyard.png` — иллюстрация двора.
- `favicon.svg` — иконка сайта.

## GitHub Pages

В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root).

Числовые примеры снабжены оговорками и источниками на странице. Отметки личного плана хранятся только пока открыта страница; внешние сообщения автоматически не отправляются.
